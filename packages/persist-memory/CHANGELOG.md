# Changelog

All notable changes to `@oimdb/persist-memory` are recorded here. This file starts at 4.1.0; releases
before it were not changelogged.

## 4.1.0

Breaking: exports renamed. Requires `@oimdb/persist` 4.1.0.

### Renamed

- `OIMPersistMemoryRecordsStrategy` → `OIMPersistMemoryRecordsService`
- `OIMPersistMemorySnapshotStrategy` → `OIMPersistMemorySnapshotService`
- `TOIMPersistMemoryStrategyOptions` → `TOIMPersistMemoryServiceOptions`
