## What one operation is on every row here

ONE FRAME — sixteen writes, the reads that frame performs, and the flush. Not one write and not one read: the two designs move work BETWEEN those halves, so a row timing either half alone would report whichever half its author picked.

NEITHER SIDE DECLARES `operationsPerPass`, and that is the honest answer rather than an omission: that field is for a side whose pass CONSUMES its fixture and can therefore only be run once, and these sides are steady state. The void version of this pair declared a per-pass count while `run` counted frames, which put every absolute figure out by the frame size and pinned the sample far below the length `measure.ts` says is worth timing.

## What the hand-written floor is given

It writes THROUGH THE SAME COLLECTION, THE SAME CHANNEL AND THE SAME EFFECTS — so the write path, the leaf list and the frame are common to both arms and cancel — and adds only what the refused design would add. It is given every advantage the design can honestly claim: its drain is LEVEL ORDERED and HELD GATED, so a change its first level absorbs never reaches the levels above, and its effect body asks the node's own stamp before doing anything, so a woken consumer whose derivation did not move is not re-run. A push that marked the whole transitive cone would be a cheaper thing to beat and is not what is measured here. Its dependent list is an array indexed by the root index the write loop has already computed, where the void version paid a hash probe for it.

THE DERIVE BODIES ARE THE SAME FUNCTIONS on both arms, and deliberately so: both sides read the same `TOIMEntitySlot` shape, so one call site stays monomorphic and the body is not part of the difference.

## The arithmetic the stated counts rest on

THE FAN-OUT IS EXACTLY TWO FOR EVERY ROOT, and it is arithmetic rather than an average: the pair `{2d, 2d+1}` shares BOTH of its derivations, so a frame of eight pairs reaches sixteen distinct derivations through thirty-two dependent visits — sixteen of which end on the floor's stamp.

THE CHANGE IS ABSORBED AT THE FIRST LEVEL BY CONSTRUCTION on the chain row. The filter keeps every row whose rank is under a ceiling no write approaches, so its verdict cannot flip; a row in which the verdict DID flip would be measuring the sort, which is a different question. THE SORT IS BY `title`, WHICH NOTHING HERE WRITES — so the absorption is real and not a hidden staleness. Sorting by the written column would make `held`'s stop a defect rather than a mechanism.
