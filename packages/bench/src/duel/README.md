# Duel

## TDuelRun

### Two rows and seventeen are different claims

A ratio over two rows and a ratio over seventeen must not look alike. This tool
measures exactly two by construction, which is its whole point and also its whole
limit.

### The two absences are not the same fact

`notAsked` is libraries this tool did not run — a fact about THE TOOL: they have
a wiring for this script and would have produced a row in `npm run bench`.
`declined` is libraries with no wiring for this script at all, each with a written
reason in its own adapter — a fact about THE LIBRARY. Collapsing them into one
number would report the tool's narrowness as fifteen findings about libraries.

### Why the two drifts are added

The noise is `arm.drift + floor.drift`, the SUM and not the larger of them: the
ratio is a quotient, so the relative errors of its halves add.
